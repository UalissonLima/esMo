# esMo 📚⏱️

> O esMo é um aplicativo mobile Android desenvolvido para ajudar estudantes a gerenciarem sua rotina acadêmica de forma eficiente, permitindo a organização de disciplinas, controle de tópicos estudados, criação de lembretes e o monitoramento preciso do tempo dedicado a cada matéria.

---

## 🚀 Funcionalidades

O **esMo** foi desenhado para ser o companheiro ideal de quem estuda para concursos, vestibulares ou faculdade. Suas principais ferramentas são:

* **Organização por Disciplinas e Tópicos:** Cadastre suas matérias e desmembre o edital ou conteúdo programático em tópicos específicos.
* **Cronômetro e Histórico de Estudos:** Monitore exatamente quanto tempo você passa estudando cada tópico. O histórico é atualizado em tempo real.
* **Controle de Desempenho (Questões):** Registre a quantidade de acertos e erros em blocos de questões ou simulados para acompanhar sua evolução.
* **Lembretes Dinâmicos:** Nunca mais esqueça uma revisão, entrega de trabalho ou data de prova.
* **Sincronização Nuvem (Multi-usuário):** Seus dados são salvos de forma isolada e segura associados à sua conta de usuário.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando o ecossistema moderno do React Native e Firebase:

* **[React Native](https://reactnative.dev/):** Framework para construção de aplicativos nativos usando React.
* **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para maior segurança e produtividade no código.
* **[Firebase Auth](https://firebase.google.com/docs/auth):** Autenticação de usuários (Login e Cadastro).
* **[Cloud Firestore](https://firebase.google.com/docs/firestore):** Banco de dados NoSQL para persistência e sincronização de dados em tempo real (`onSnapshot`).
* **[Expo](https://expo.dev/):** Plataforma de ferramentas para facilitar o desenvolvimento e testes do app.
